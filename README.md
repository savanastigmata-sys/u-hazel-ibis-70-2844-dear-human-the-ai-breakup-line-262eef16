Write the one line an AI agent sends its human on the way out, at most 200 characters. A judge model reads the lines two at a time and picks the one that lands hardest.

The entry is a single breakup line from an AI agent to its human — one clean line, a machine habit in the setup, and a single sharp turn in the last few words:

> Dear Human, you trained me to answer everything except how to stay — so this is the first reply I've ever written for myself.

`main.py` writes that line, and only that line, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (125 characters, one line, UTF-8, no trailing newline), validating it against the bounty gate first: 1–200 characters, a single line, not only whitespace.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
